# Journal des choix

## 2026-11-17 – Système d'exploitation

- **Décision :** utiliser Ubuntu avec WSL sous Windows.
- **Autres possibilités :** Linux installé directement ou macOS.
- **Raison :** Ubuntu permet d'apprendre les commandes Linux et de travailler dans un environnement de développement.

## 2026-11-17 – Éditeur de code

- **Décision :** utiliser Visual Studio Code.
- **Autres possibilités :** Sublime Text, Notepad++ ou Vim.
- **Raison :** VS Code propose des extensions et des outils pratiques pour développer.

## 2026-11-17 – Installation de Node.js

- **Décision :** installer Node.js avec le dépôt NodeSource et apt.
- **Autres possibilités :** le paquet nodejs d'Ubuntu ou le site nodejs.org.
- **Raison :** NodeSource propose une version LTS récente et facilite l'installation.
